# Référence de placement — commandes Windy compactes

La référence fournie montre un groupe horizontal sombre positionné dans la zone basse de la carte. Le bouton de recentrage est à gauche ; les boutons **+** et **−** sont au centre du groupe, dans deux zones contiguës de même taille. Le contrôle plein écran est un élément indépendant sur le bord droit de la carte.

Cette disposition sert uniquement de guide de placement pour la vue compacte. L’aperçu reste non interactif afin de bloquer le panoramique tactile de l’iframe externe.
